# CivilBridge

This repository's active project lives in the `Civilbridge/` directory.

## Project Layout

- `Civilbridge/front` - React frontend
- `Civilbridge/back` - Node/Express backend

## Start Here

- App documentation: `Civilbridge/README.md`
- Frontend: `Civilbridge/front`
- Backend: `Civilbridge/back`

## Quick Start

```bash
cd Civilbridge/back
npm install
npm run dev
```

```bash
cd Civilbridge/front
npm install
npm run dev
```
